## Needs human visual approval

Every candidate above is selected from **metadata + descriptions only**. Before
import, a human must visually confirm: composition and text-safe area (hero
contrast), no unintended faces/branding/licensing issues, that the image truly
matches its proposed context, and overall on-brand calm coastal feel.

## Needs optimization before repo import

No source file ships as-is. Required per asset: verify license → resize to actual
rendered dimensions → convert to **WebP/AVIF** (or well-compressed JPEG) → strip
metadata → add **descriptive alt text** → only then place in repo. The hero (LCP)
image must be carefully sized and prioritized; everything else lazy-loads. Source
stills run 0.4–35 MB and videos up to ~2.4 GB — none are web-ready unprocessed.
